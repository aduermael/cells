A spreadsheet engine for agents

A lightweight and fully scriptable CLI primarily, with a web UI for humans to see and collaborate.

Try it right here 👇 You can drag&drop .csv & .xlsx files, everything stays in your browser.

Why Cells

  • Made for agents — headless CLI with context-window-conscious structured outputs; code as the main request interface. No harness, no system prompts.
  • Scriptable — native Luau runtime (Python, VBA, and TypeScript planned)
  • Real-time collaboration — WebRTC peer-to-peer sync with CRDTs; humans and agents in the same room
  • Excel compatible — import and export .xlsx and .csv
  • Git-friendly — text-based .zcd format (one entity per line, clean diffs)

Early project — about 120 formulas today (vs ~500 in Excel); charts not yet supported.

Built for AI agents to work with

Cells is not an agent itself. It defines no harness and no system prompts. The CLI is designed so agents can convert, inspect, create, and transform workbooks — and join collab rooms via long-running sessions.

Install the agent skill (recommended), then prompt for spreadsheet work like "Open file.xlsx and fix formulas": 

curl -fsSL https://raw.githubusercontent.com/aduermael/cells/main/install-skill.sh | sh

Fully scriptable

Luau is built in from day one — in the web UI and on the CLI. Run inline expressions or script files against any supported format. 

# Run inline script
cells -i data.csv output.xlsx -e 'setCell("A1", 100)'

# Run a script file
cells -i data.xlsx output.csv --script transform.luau

# Script-only mode (inspect without writing an output file)
cells -i report.xlsx --script analyze.luau
cells -i data.csv -e 'print(getCell("A1"))'

Native .zcd format & collaboration

.zcd (Zero Conflict Document) is plain text on purpose — built for collab and clean git diffs:

  • One entity per line — edit a cell, column, or row → exactly one line changes
  • Content-addressed styles — same style encodes to the same blob (auto-deduped)
  • CRDT operation log — full edit history for sync and conflict resolution

Realtime sync is WebRTC peer-to-peer. A small signaling server only helps peers find each other; document ops travel between clients, not through a central store. Concurrent edits merge automatically. 

# Join a collab room from the CLI (multi-step agent work)
cells session start 'https://cells-app.fly.dev/?room=YOUR_ROOM'
cells session exec SESSION_ID -e 'setCell("A1", 1)'

Install the CLI

  1. Agent skill (recommended for agentic workflows) — curl -fsSL https://raw.githubusercontent.com/aduermael/cells/main/install-skill.sh | sh
  2. Homebrew — brew install aduermael/tap/cells
  3. Direct binary — curl -fsSL https://raw.githubusercontent.com/aduermael/cells/main/install.sh | sh
  4. From source — bazel run :cli → dist/cli/cells
