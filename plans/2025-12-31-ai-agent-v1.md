## Overview

Implement the first version of an AI agent that can explore and modify spreadsheets by generating and executing Luau code. The agent will be accessible via HTTP endpoints on the Go server, with the client handling code execution and displaying results.

### Architecture

```
┌─────────────┐     POST /prompt      ┌─────────────┐    Anthropic API    ┌─────────────┐
│   Browser   │  ─────────────────▶  │  Go Server  │  ◀───────────────▶  │   Claude    │
│   (Client)  │  ◀─────────────────  │  (HTTP SSE) │     (streaming)     │    API      │
└─────────────┘   SSE stream          └─────────────┘                     └─────────────┘
      │                                     │
      │ execute_code tool call              │ conversation stored in memory
      │ (client executes Luau)              │ (keyed by conversation_id)
      │                                     │
      │         POST /resume               │
      └─────────────────────────────────────┘
           (send tool result back)
```

### Message Flow

1. Client sends user prompt to `/prompt` with optional `conversation_id`
2. Server creates/retrieves conversation, appends user message
3. Server calls Anthropic API with streaming
4. Server streams events to client via SSE:
   - `message_start` - includes message ID
   - `content_delta` - text chunks
   - `tool_use` - tool call (execute_code)
   - `message_end` - signals completion
5. If tool call received, client executes Luau code locally
6. Client sends result to `/resume` with message ID
7. Server continues conversation with tool result

### Tool Definition

```json
{
  "name": "execute_code",
  "description": "Execute Luau code to interact with the spreadsheet. Available APIs: cellGet(ref), cellSet(ref, value), sheetSelect(index), sheetGetName(index), sheetSetName(index, opts), rangeSelect(opts), rangeDelete(opts), columnSetWidth(col, opts), rowSetHeight(row, opts), columnMove(col, opts), documentSetTitle(title). Use print() for output.",
  "input_schema": {
    "type": "object",
    "properties": {
      "code": {
        "type": "string",
        "description": "Luau code to execute"
      },
      "description": {
        "type": "string",
        "description": "Brief description of what this code does"
      }
    },
    "required": ["code", "description"]
  }
}
```

## Implementation Notes

### SSE Event Format

```
event: message_start
data: {"id": "msg_123", "conversation_id": "conv_456"}

event: content_delta
data: {"text": "I'll help you "}

event: content_delta
data: {"text": "modify the spreadsheet."}

event: tool_use
data: {"id": "tool_789", "name": "execute_code", "input": {"code": "cellSet('A1', 42)", "description": "Set A1 to 42"}}

event: message_end
data: {"stop_reason": "tool_use"}
```

### Request/Response Formats

**POST /prompt**
```json
{
  "prompt": "Set cell A1 to 'Hello'",
  "conversation_id": "optional-existing-id"
}
```

**POST /resume**
```json
{
  "conversation_id": "conv_456",
  "message_id": "msg_123",
  "tool_results": [
    {
      "tool_use_id": "tool_789",
      "content": "Success: Cell A1 set to 'Hello'"
    }
  ]
}
```
