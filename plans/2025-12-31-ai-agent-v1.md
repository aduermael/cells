## Overview

Implement the first version of an AI agent that can explore and modify spreadsheets by generating and executing Luau code. The agent logic lives in C++ using the existing platform abstraction layer, enabling both web (WASM) and headless (CLI) usage.

### Architecture

```
┌─────────────────────────────────────────────────────────────────────┐
│                           C++ Core                                   │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐             │
│  │   Agent     │───▶│ HttpRequest │───▶│  Anthropic  │             │
│  │  Manager    │    │ (streaming) │    │     API     │             │
│  └─────────────┘    └─────────────┘    └─────────────┘             │
│         │                                                           │
│         │  execute tool                                             │
│         ▼                                                           │
│  ┌─────────────┐                                                    │
│  │   Luau      │                                                    │
│  │  Sandbox    │                                                    │
│  └─────────────┘                                                    │
└─────────────────────────────────────────────────────────────────────┘
         │                              │
         │ WASM bindings               │ Native
         ▼                              ▼
┌─────────────────┐            ┌─────────────────┐
│   Web Client    │            │   CLI/Headless  │
│  (chat panel)   │            │                 │
└─────────────────┘            └─────────────────┘
```

### Message Flow

1. User enters prompt in chat panel (or CLI)
2. C++ `AgentManager` receives prompt, manages conversation state
3. `AgentManager` calls Anthropic API via `HttpRequest` (streaming)
4. Text chunks streamed to UI via delegate callbacks
5. When `execute_code` tool called, `AgentManager` executes via `LuauSandbox`
6. Tool result appended to conversation, API called again
7. Continues until assistant stops with `end_turn`

```json

      "description": {
        "type": "string",

```

## Implementation Notes

### Anthropic API Request

```
POST https://api.anthropic.com/v1/messages
Headers:
  x-api-key: <key>
  anthropic-version: 2023-06-01
  content-type: application/json

Body:
{
  "model": "claude-sonnet-4-20250514",
  "max_tokens": 4096,
  "stream": true,
  "system": "<system prompt>",
  "tools": [<execute_code tool>],
  "messages": [...]
}
```

### SSE Event Types from Anthropic

```
event: message_start
data: {"type":"message_start","message":{"id":"msg_...","role":"assistant"}}

event: content_block_start
data: {"type":"content_block_start","index":0,"content_block":{"type":"text","text":""}}

event: content_block_delta
data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"Hello"}}

event: content_block_start
data: {"type":"content_block_start","index":1,"content_block":{"type":"tool_use","id":"toolu_...","name":"execute_code","input":{}}}

event: content_block_delta
data: {"type":"content_block_delta","index":1,"delta":{"type":"input_json_delta","partial_json":"{\"code\":"}}

event: content_block_stop
data: {"type":"content_block_stop","index":1}

event: message_delta
data: {"type":"message_delta","delta":{"stop_reason":"tool_use"}}

event: message_stop
data: {"type":"message_stop"}
```

### AgentManagerDelegate Interface

```cpp
class AgentManagerDelegate {
public:
    virtual ~AgentManagerDelegate() = default;

    // Streaming text from assistant
    virtual void onAgentTextDelta(const std::string& text) = 0;

    // Tool use detected (before execution)
    virtual void onAgentToolUse(const std::string& tool_id,
                                 const std::string& name,
                                 const std::string& input_json) = 0;

    // Tool execution complete
    virtual void onAgentToolResult(const std::string& tool_id,
                                    bool success,
                                    const std::string& output) = 0;

    // Message complete (stop_reason: end_turn or tool_use)
    virtual void onAgentMessageComplete(const std::string& stop_reason) = 0;

    // Error occurred
    virtual void onAgentError(const std::string& error) = 0;
};
```
