## Overview

Implement the first version of an AI agent that can explore and modify spreadsheets by generating and executing Luau code. The agent logic lives in the **Go server** (not C++) to keep the API key server-side.

### Design Decisions

- **API key server-side only**: Read from `ANTHROPIC_API_KEY` env var, never exposed to client
- **Conversation state server-side**: Stored in memory (ephemeral, lost on restart)
- **No code confirmation**: Auto-execute code immediately for simplicity
- **Collapsible messages**: Chat messages can be minimized (showing last few lines) independently from input area

### Message Flow

1. User enters prompt in chat panel
2. Client sends prompt to server via `POST /api/agent/message`
3. Server streams Anthropic response back via SSE
4. When `execute_code` tool is requested:
   - Server sends tool request to client
   - Client executes code via WASM `LuauSandbox`
   - Client sends result back via `POST /api/agent/tool-result`
5. Server continues conversation with tool result
6. Loop continues until `end_turn`

### Tool Definition

```json
{
  "name": "execute_code",
  "description": "Execute Luau code to interact with the spreadsheet. API: getCell(ref, {create?}):Cell?, setCell(ref, value), getSheet({name?|index?}|name|index):Sheet?, selectSheet(sheet|name|index), addSheet(name?):Sheet, selectRange(range), deleteRange(range), fillRange({from, to}), setColumnWidth(col, {width}), setRowHeight(row, {height}), moveColumn(col, {to}), setDocumentTitle(title), getDocumentTitle():string. Cell has .value, .formula, .ref, .dependents, .dependencies. Sheet has .name. Use print() for output.",
  "input_schema": {
    "type": "object",
    "properties": {
      "code": {
        "type": "string",
        "description": "Luau code to execute"
      }
    },
    "required": ["code"]
  }
}
```

## Implementation Notes

### Server Events (SSE format)

```
event: text
data: {"text": "Let me check the spreadsheet..."}

event: text
data: {"text": " I'll read cell A1."}

event: tool_use
data: {"id": "toolu_123", "name": "execute_code", "input": {"code": "print(getCell('A1').value)"}}

event: tool_result_needed
data: {"tool_use_id": "toolu_123"}

event: text
data: {"text": "The value in A1 is 42."}

event: done
data: {"stop_reason": "end_turn", "conversation_id": "conv_abc"}
```

### Client → Server API

```
POST /api/agent/message
Content-Type: application/json

{
  "prompt": "What's in cell A1?",
  "conversation_id": "conv_abc"  // optional, omit to start new conversation
}

Response: SSE stream (see above)
```

```
POST /api/agent/tool-result
Content-Type: application/json

{
  "conversation_id": "conv_abc",
  "tool_use_id": "toolu_123",
  "result": "42",
  "is_error": false
}

Response: SSE stream (continuation)
```
