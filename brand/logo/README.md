# Cells logo options

Black SVG: **cell** + **prompt `>`** + **selection handle**.

- Entire mark fits a **square**
- Handle stays **inside** that square  
- **Gap** around the handle in the BR corner  
- Handle sits on the **BR border zone** (spreadsheet-style, inset to keep gap + in-bounds)
